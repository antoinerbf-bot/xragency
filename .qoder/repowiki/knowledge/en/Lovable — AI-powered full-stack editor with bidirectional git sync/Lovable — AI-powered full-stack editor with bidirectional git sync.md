This project is a Lovable-generated site. The repository is connected to the Lovable editor (https://lovable.dev) so that commits pushed to the connected branch sync back into the editor and published history is preserved. Do not rewrite or force-push already-published git history, as it will corrupt Lovable's side of the history. Development workflow: edit in Lovable or locally; push to keep them in sync.
