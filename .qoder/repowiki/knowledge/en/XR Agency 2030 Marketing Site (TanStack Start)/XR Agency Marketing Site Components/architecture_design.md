Flat collection of single-purpose React components under `src/components/site/`, each exporting one default component that renders a full `<section>` (e.g. `Hero.tsx`, `Intelligence.tsx`, `Services.tsx`, `Pricing.tsx`, `Work.tsx`, `About.tsx`, `Contact.tsx`, `Faq.tsx`). A shared `primitives.tsx` file centralizes reusable building blocks consumed by every section: `Logo`, `Parallax` (scroll-driven transform via `requestAnimationFrame`), `Reveal` (IntersectionObserver-triggered `ember-rise` animation), `ChapterMarker`, `SectionHeading`, and `EmberButton`. Visual decoration is isolated in `Globe.tsx` (pure SVG globe with star field) and reused from `Hero` and `Intelligence`. Data and copy are never hard-coded inside components: text goes through `useLang().t()` from `@/lib/i18n`, UI strings come from `@/lib/copy` (`UI`), service/pricing data from `@/lib/content` (`SERVICES`, `CONTACT`), and prices are formatted via `price()`. Styling uses Tailwind utility classes combined with the project's `cn` helper; animations rely on CSS keyframes (`ember-rise`, `animate-pulse-soft`, `animate-slow-spin`) defined elsewhere. The module has no internal sub-packages — dependency direction is strictly outward to `@/lib/*` and inward only via the sibling `Globe` component.
