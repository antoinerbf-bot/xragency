Each file in `src/components/ui/` exports one or more atomic UI primitives that wrap a corresponding `@radix-ui/react-*` primitive (e.g. `dialog.tsx` wraps `@radix-ui/react-dialog`, `accordion.tsx` wraps `@radix-ui/react-accordion`). Components are pure presentational wrappers: they compose Radix primitives with Tailwind utility classes via the shared `cn` helper from `@/lib/utils`, add consistent styling and accessibility attributes, and re-export the composed pieces. Complex primitives (button, sheet) use `class-variance-authority` (`cva`) to define variant/size prop sets. The form system (`form.tsx`) builds a higher-level API over `react-hook-form` by composing `FormProvider`, `Controller`, and local React contexts (`FormFieldContext`, `FormItemContext`) exposed through `useFormField`. Cross-component references are kept minimal — `form.tsx` imports `Label` from `@/components/ui/label`, while other files depend only on `@/lib/utils` and external libraries; there is no internal barrel/index file, so consumers import directly from each component file.
