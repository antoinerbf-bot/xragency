The root configures a TanStack Start + Vite + Nitro stack via `@lovable.dev/vite-tanstack-config` in `vite.config.ts`, which auto-installs plugins for React, Tailwind v4, path aliases (`@/*` → `src/*`), and server-side rendering. The `app_entry` module provides the TanStack router, middleware, and file-based routes that compose `site_components` (marketing sections) on top of `ui_primitives` (Radix/Tailwind primitives). All children consume `shared_libs` for multilingual content, pricing helpers, error capture, and the mobile-breakpoint hook. A single `package.json` pins the shared dependency graph (React 19, Radix, Tailwind, Zod, React Query), while `tsconfig.json` enforces strict TS across all modules and `eslint.config.js` + Prettier provide cross-cutting lint/format rules.
