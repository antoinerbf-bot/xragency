# XR Agency

Site premium XR Agency — Studio digital & IA.

## Live

- Production (Vercel) : https://xragency.vercel.app/
- Preview Lovable (référence) : https://fusion-prime-studio.lovable.app

## Stack

- TanStack Start + React 19
- Tailwind CSS v4
- Vite
- i18n : FR / EN / VI (prix en € / $ / VND)
- Configurateur IA de devis

## Développement local

```bash
npm i
npm run dev
```

Le site tourne sur http://localhost:8080

## Structure principale

- `src/components/site/` — sections du site (Hero, Services, Pricing, FAQ, Contact, Intelligence…)
- `src/lib/copy.ts` — textes multilingues
- `src/lib/i18n.tsx` — système de traduction
